## MKCloud IXP 是什么？和 IEPL、IPLC 差在哪

IXP 是借助互联网交换点（IXP，Internet Exchange Point）对接主流云厂商的上云专线：流量先在云厂商内网走优化通道出境，再落到境外节点。IEPL 和 IPLC 则是传统点对点专线，入口和出口都分配独享公网 IP，两者区别在承载技术——IEPL 走二层以太网，扩容灵活；IPLC 是传统租用电路，胜在稳。

差别集中在入口侧。IEPL/IPLC 的入口是独立公网 BGP，广港 IEPL 用的是 UCloud 广州八线 BGP 配合香港侧优质出口，端内延迟能压到 1–3ms；IXP 的入口在云厂商内网，想用这条线，前提是有一台同厂商的国内云服务器做前置。境外端倒是一样的逻辑，套餐自带 KVM 实例，2TB 年付版对应 2 核 4GB 内存、40GB SSD。

有第三方评测把 IXP 比作“商务舱和头等舱的关系”：依然比走公网稳得多，但省掉了独享专线的钱。对大多数跨境业务来说这个比喻成立，前提是那台前置机你本来就用得上。

产品线还有两个方向值得知道：沪港 IPLC（评测中提到，公开资料未见报价），以及面向有被攻击风险业务的福建高防入口，具体价格都要去官网确认。

## 前置机怎么搭？实际成本要算两笔

搭建顺序是先有云服务器、再买专线：在阿里云或腾讯云等主流厂商开通一台国内地域的云服务器，然后购买 IXP 套餐，业务跑在云服务器上，流量经云内网优化通道转到境外节点落地。

具体三步：

1. 开通或复用一台国内云服务器（阿里云、腾讯云等主流厂商均可）
2. 购买 MKCloud IXP 套餐，境外端分配配套的 KVM 实例（2TB 年付版为 2核4G、40GB SSD）
3. 部署业务，让流量走云内网优化通道出境，境外端实例负责落地

成本要算两笔。明面上的是套餐费，1168 元/年；容易被忽略的是前置机，按云厂商和配置另算。这笔账直接决定 IXP 适不适合你：

- 本来就有云服务器：前置成本为零，IXP 是全线单位流量价格最低的方案，2TB 月流量对中小业务相当宽裕
- 需要新买前置机：把云服务器月费加进去，再和广港 IEPL 228 元/月对比，价差会明显缩小
- 只打算短期用：前置机按年买反而不划算，低频使用未必适合 IXP

## 哪些人适合 IXP，哪些人该加钱上 IEPL/IPLC

判断标准其实就一条：你是否需要别人能直接访问的独立公网入口 IP。

按场景拆开：

- 云上业务出海（电商后台、跨境 SaaS、数据同步）：业务本来就在云服务器上，IXP 等于给现有机器加一条低价跨境通道，1168 元/年的价位在全线找不到对手
- 建站、代理转发、境外服务部署：这些场景需要入口 IP 能被直接访问，IXP 的云内网入口满足不了，老老实实上广港 IEPL 或沪日 IPLC
- 对延迟敏感的应用：广港 IEPL 端内 1–3ms 是全线最低，IXP 没有公开延迟数据，追求确定性就选 IEPL
- 目标市场在欧美：沪美 IPLC 延迟 124–134ms，物理距离摆在那里，专线解决的是稳定问题，别指望延迟奇迹

## 下单前值得确认的几件事

实名认证、系统限制、合规要求、退款条件，这四项都写在条款层面，下单前值得逐条过一遍。

- 实名认证：需要国内身份证信息和手机号，介意这点的只能绕行
- 系统限制：KVM 架构，支持各类 Linux 发行版，不支持 Windows，业务依赖 Windows 的直接排除
- 合规要求：官方明确只允许合规用途，违规封号且不退款
- 退款条件：退款只针对能证实的质量问题，官方也不保证流媒体解锁。评测给出的实操建议是开通后第一时间留证据——不同时段各跑一轮 ping、traceroute 查回程、实测一次真实带宽，万一后续需要申请退款，这些记录就是依据

还有一个容易漏掉的细节：评测资料里 IEPL 套餐的流量标注为双向计（Bi-directional），实际可用量会比表面数字少。你买哪个套餐，都建议下单前和客服确认计量口径。

## 常见问题

**IXP 专线有独立公网 IP 吗？**
入口没有。IXP 的入口走云厂商优化通道，独立公网 IP 是 IEPL/IPLC 的配置；境外端实例的网络细节，下单前可以在官网确认。

**买 IXP 还要单独买云服务器吗？**
要。官方页面明确标注 IXP 产品需要单独购买云厂商前置机搭配使用，已有的云服务器可以直接复用。

**支持 Windows 吗？**
不支持。KVM 架构下只能装 Linux 发行版。

**能退款吗？**
只有能证实的质量问题才在退款范围内，“不想要了”不行。开通后先测延迟、回程和带宽，留好记录再说。

**访问香港、日本、美国分别怎么选？**
香港、台湾方向选广港 IEPL；日韩方向选沪日 IPLC 或沪日 IXP；欧美方向选沪美 IPLC。IXP 特惠机此前出过沪港和沪日方向，标准套餐的在售方向以官网为准。
